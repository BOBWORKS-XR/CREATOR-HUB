# Creator Hub 0.1.0-alpha.4

Windows hotfix prerelease. This updates Hub; the accepted MCP and Project Setup
releases are unchanged.

## New in This Update

- **Recently modified projects first**, with **Name A-Z**, search and SDK filters.
  Dates come from saved project source files, not Unity's generated cache.
- **Clearer update blockers:** process IDs, executable paths and the starting app
  when identifiable. No Codex-only assumptions; other MCP clients are supported.
- **Check again** refreshes local status without installing or closing anything.
  Recovery guidance covers connections that remain after their app is closed.
- Conservative matches are labelled **Possible MCP connection** instead of claiming
  certainty. Unknown processes still block an unsafe update.

## Install or Update

1. Save your work and close the old Creator Hub window normally.
2. Run `Creator-Hub-0.1.0-alpha.4-Windows-setup.exe` using the existing/default folder.
3. Open Hub. Your MCP, Project Setup and saved project selections stay in place.

New users can install MCP or Project Setup from Hub. **Project Setup is optional**;
MCP does not require it. Leave **Include prereleases** enabled for these previews.
For an MCP update, disconnect its connection in your AI client when prompted,
then choose **Check again** and approve the update separately. Do not uninstall
MCP simply to close its running connection.

Accepted companion versions remain MCP **2.7.0-alpha.1** and Project Setup
**0.3.0-alpha.1**. Their installers, hosted-app pins and payloads were not changed.

## Tested

- 49 Rust tests, 66 browser tests, strict lint and packaging checks.
- Exact-installer clean installation, active-Hub refusal, same-version reinstall
  and upgrade from the published Hub alpha.3, preserving existing content/settings.
- Fresh companion installations, legacy upgrades and MCP-only upgrades without Setup.
- Actual private-runtime blocker display, persistent recheck, native update refusal,
  cooperative exit and a separately approved update. The fixture is not a real
  in-flight MCP request or a claim that every client shutdown issue is resolved.
- Both installed hosted apps, native consent, retained forms, MCP settings round-trip,
  busy-close protection and normal backend shutdown.
- Local alpha.3 upgrade, real project sorting and both hosted apps, with companion
  binaries, MCP settings and existing private-runtime processes preserved.

## Limits

- Windows x64 prerelease, not a stable release. macOS/Linux installation is not supported.
- The installer is **not Windows publisher-signed**. Signed update metadata and
  SHA-256 checksums are separate from Authenticode/SmartScreen trust.
- Installer-driven upgrades passed. A complete signed **in-app Hub self-update
  and restart** to a higher version remains untested.
- Historical BANTWORKS/MSI, unknown, duplicate and custom-folder installations
  remain guarded; no automatic downgrade or forced client termination was added.
- No Unity project creation, SDK migration, headset or multiplayer claim is made
  by these installer tests. Existing Unity projects and bridges are not modified.

The released installer is the exact GitHub-built and accepted artifact.
Attached reports bind its installer and actual installed executable hashes.
