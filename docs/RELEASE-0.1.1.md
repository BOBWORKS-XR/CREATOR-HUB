# Creator Hub 0.1.1

- The app menu stays on screen while scrolling Creator Plugins.
- Plugins uses its puzzle-cube icon and Creator Plugins heading, returning to
  Creator Hub when you leave the page.
- Plugins opens in Grid by default, with a persistent List/Grid choice in Hub
  and its Unity window. Grid cards have aligned action buttons.
- Update MCP and Project Setup directly from Hub's Apps page. Installation still
  asks for approval; busy apps and active MCP connections remain protected.
- Recognized earlier Unity menu packages can be updated with a retained backup.
  Modified files and existing project content are not overwritten.

MCP 2.7.0 and Project Setup 0.3.0 remain the supported companion releases. This
updates Hub and the Unity helper it supplies, not those standalone installers.
Unity menus already installed in a project need an explicit Update menu action.

Windows x64. Save work and close Hub before running the installer. Windows may
show an unsigned publisher warning; signed update metadata and package checksums
are separate from Authenticode or code-safety review.

Older previews that report an intermediate Hub version can use the installer
from this page. Public 0.1.0 assets and tags have not been replaced.
