# Builder setup check-in

For a Discord thread or an individual support reply. Include people on old
versions and people whose setup works. They do not need to update to answer.

> How do you usually connect your AI app to Unity? We're trying to make the
> move from the old MCP app easier. Could you reply with these three lines?
>
> - App and version you see (in Creator Hub, look at the bottom of Home):
> - Where you open MCP: Menu in Creator Hub / Apps page in the old Hub / separate MCP app / directly in my AI app / not sure
> - How it's going: working / stuck setting up / stuck moving to Hub / stuck updating / stopped connecting
>
> "Not sure" is fine. If a button or message was confusing, which one?
> No logs, settings files or project names needed.

## Using the answers

Keep the app name with its version: a standalone MCP version is not a Hub
version. The in-app check-in shows the currently running Hub version, not the
version a builder upgraded from. Count responses by version, entry point and outcome. Count a follow-up
from the same person on the same setup once, and keep unknowns as unknowns.
These are voluntary replies, not a count of everyone using Hub.

Use repeated reports to choose the next test. A working connection marked
unconfigured calls for a status-label check; a failed connection calls for a
bridge check. For a move that stalls, reproduce the reported starting version
and migration state on a disposable installation instead of asking the builder
to delete settings. After changing a flow, ask whether the same step now works.
