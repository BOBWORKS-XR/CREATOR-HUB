# Creator Hub 0.1.22 (Windows)

New projects select the latest stable Creator SDK from verified registry metadata. If lookup fails, choose an explicit retry or the tested fallback. Existing projects are not automatically upgraded.

Updater messages now distinguish version, path and verification failures. Project-lock messages distinguish held markers from unverified locks without claiming ownership. MCP status describes recently written state files without treating recency as proof of a live connection. Existing refusal and installer-identity checks remain in place.

New official builds are Windows only. Existing Mac/Linux downloads and source remain available; their historical assets are unchanged.

This is staged release metadata, not public-update acceptance or a ready/latest claim. See [qualification](WINDOWS-022-QUALIFICATION.md).
