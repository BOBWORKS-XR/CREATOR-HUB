# Post 1: Creator Works MCP 2.7.0 Is Out

**Your AI tools, connected to Unity. Now with Creator Plugins.**

- Work with scenes, prefabs, components and Visual Scripting, with Creator SDK and Banter project awareness.
- **New Plugins catalogue:** browse community creations with previews, creator credit and setup instructions. MCP tools and AI skills have their own categories too.
- **Add a Creator Plugins window inside Unity**, then import supported packages into your project. Cancelled imports can be retried without reopening the window.
- Improved upgrade checks protect existing settings and tell you when an active app or connection needs closing.

**Prefer everything together? Creator Hub is now available:** download, update and open MCP and Project Setup in one place, alongside your projects and Plugins. **MCP still works standalone.**

Windows x64 release. Feedback and bug reports welcome. Unity still asks which package files to import; publisher signing is not in place yet.

# Post 2: Creator Hub Is Out: Less Setup, More Creating

**Creator Hub brings your projects, Project Setup, MCP and community Plugins together.**

**Project Setup 0.3.0**
- Name your project, choose a folder and **Set up and create**. It checks requirements and installs supported missing tools after your approval.
- The pinned Unity version, Creator SDK and URP, with **Android and Windows requirements included**.
- Visible download progress, Visual Scripting configuration and validation before the project is ready.
- Clearer errors and local logs when something fails, plus inspection and backed-up repairs for existing projects.

**Creator Hub 0.1.0**
- Opens on **your Altspace/Creator SDK and Banter projects**, without digging through unrelated Unity projects.
- Download, install, update and open MCP and Project Setup inside Hub. **Both also work standalone.**
- **Creator Plugins is built in across the apps.** Browse creations, or add its catalogue window to Unity and import supported packages there.

**Creator Converter is coming later.** Share plugins, graphs, prefabs, MCP tools or AI skills through the [community submission form](https://github.com/SideQuestVR/Creator-Community/issues/new?template=contribution.yml).

Windows x64 release. Unity licence/sign-in and administrator prompts still need you. Publisher signing is not in place yet; feedback is welcome.
