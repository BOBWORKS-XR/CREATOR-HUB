# Creator Hub 0.1.19: Windows Hotfix

Prepared for release; not yet published.

- Project opening now distinguishes an unused Unity lock marker from an active
  Editor and provides nearby retry and recovery actions.
- Existing-project repair uses that project's installed Editor. It no longer
  requires the new-project URP template.
- Newer SDK and Unity versions are preserved. Setup reads installed SDK
  requirements and offers backed-up repairs where supported, with clear limits
  on unqualified runtime validation. It does not silently downgrade packages.
- SDK guidance explains updating through Unity, finishing import/compilation,
  and inspecting again. Failed preference loading has a read-only retry.

Windows x64 only. Historical Mac/Linux downloads remain available; no new
Mac/Linux binaries are included. Source builds remain experimental on those
platforms, and experienced maintainers are welcome.

Back up projects before repairs. Update-integrity signatures are separate from
Windows Authenticode publisher signing. The installer is not publisher-signed.
Unity sign-in, licensing and platform security prompts remain user actions.

The exact package and acceptance boundaries are recorded in
[the qualification scope](0.1.19-qualification-DRAFT.md). Passing graph or
project validation does not establish multiplayer gameplay correctness.
