# Creator Hub 0.1.18: Windows Candidate

Unpublished qualified candidate. Exact Windows installation, incoming update, migration and outgoing update checks passed; main's final publication checks remain required.

First-party Projects, Creator Works MCP and Setup / Repair run within Creator Hub. This candidate also fixes the Windows separator comparison that could reject an app-generated, already-owned router entry. The fix does not adopt other paths or relax ownership and argument checks.

Windows x64 is the maintained binary release target. Official Linux binaries are discontinued; new Mac builds remain paused. Historical downloads and source remain available. Experienced Linux and Mac maintainers are welcome.
