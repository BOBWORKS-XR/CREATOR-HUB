      Project Setup help

      This app creates and validates Unity projects for the Creator SDK.

      What does each Creator app do?

      Project Setup installs/checks supported prerequisites and creates or validates projects. It is not the AI tool. Creator Works MCP connects a compatible AI client to Unity. Creator Hub manages the apps and your projects. The Creator Plugins catalogue is available in Hub and its Unity Editor window.

      Why does setup ask for Unity or Android components?

      The approved project recipe requires a matching Unity Editor and selected build modules. Setup can download supported components after you approve, but Unity account sign-in/licensing and any operating-system administrator prompts remain yours to complete.

      Unity setup failed or is taking a long time

      Check the current activity and error first. Editor and Android tool downloads can be large; slow network or disk activity may extend setup. Retry only after checking available disk space and that Unity Hub/Unity are not actively changing the same installation. The app preserves the project and provides a local log when setup stops.

      Can I use an existing project?

      Use the Existing project view to inspect first. Repairs require a separate approval and a safety backup. Close the project in Unity when requested, review the proposed changes, and keep another backup outside the project folder.

      Where do community plugins go?

      Plugin formats differ: graphs, prefabs, scripts, editor extensions and scenes have different import steps and dependencies. Read the listing instructions and verify Unity/SDK compatibility. Do not assume adding a package is the same as setting up the Creator SDK project.

      What should I include in a support report?

      Include this app’s version, the exact stage/message, and the local setup log. Remove account details, access tokens and private project information before sharing. Support is not guaranteed; keep independent backups of important projects.
