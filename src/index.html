    Creator Hub help

    What each tool does and where to start.

    Which tool do I need?

    Creator Hub brings your Creator tools and Unity projects together. Project Setup creates and validates a Creator SDK project. Creator Works MCP connects a supported AI client to Unity tools. Setup is not the MCP.

    MCP or Setup is unavailable

    In unified Creator Hub, MCP and Project Setup are included. Open them from the Creator tools menu; no separate app installation is needed. Read any error shown and check for a Creator Hub update. Unity Editor licensing and sign-in remain with Unity.

    My AI cannot see MCP tools

    Open Creator Works MCP and use its Connection guide when available, or check the existing client setup controls. Claude Code and Claude Desktop are separate clients; the Claude website is not Claude Desktop. Compatible MCP builds offer Desktop configuration on Windows and macOS, not Linux. Fully quit and reopen a changed client, then ask your AI to call get_bridge_status. Saved settings alone do not prove a live connection. The AI model and billing come from your chosen client/provider, not MCP.

    AI token or usage costs are high

    Charges depend on your AI provider, client and model. Check provider billing and usage limits, reduce unnecessary context, disable fast/high-cost modes where available, and try a less expensive model for routine MCP tasks. MCP cannot set or cap your provider’s charges.

    Something failed

    Read the message shown in the app first. Retry discovery for app status, or refresh the relevant list. For project operations, close the project in Unity when asked and keep a separate backup. Include the app version and its local log when reporting a problem; remove private project paths or credentials first.

    Windows Defender blocks or quarantines a component

    If Microsoft Defender blocks or quarantines a Hub, MCP or Setup component, stop the affected operation and leave the file quarantined while it is reviewed. Do not assume a false positive or restore or allow an unknown file.

    In Windows Security, open Virus & threat protection > Protection history. Record the exact detection name, affected file path, time, app/component version and build, and download source. Update Defender security intelligence (definitions) under Virus & threat protection > Protection updates > Check for updates, then report the details to the developer. Remove credentials and unrelated private information from the report.

    An unsigned-app or SmartScreen "unrecognized app" reputation warning is different from a malware or Trojan detection. Check the exact message; a familiar app name or a reputation warning does not prove a file is safe.

    Do not disable Defender or add ignore/exclusion rules for Node.js, PowerShell, Unity, projects or app folders. Microsoft advises reviewing and classifying detections before considering exclusions; exclusions reduce protection.
