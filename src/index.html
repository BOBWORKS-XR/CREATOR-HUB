    Creator Hub help

    What each app does and where to start.

    Which app do I need?

    Creator Hub brings your Creator tools and Unity projects together. Project Setup creates and validates a Creator SDK project. Creator Works MCP connects a supported AI client to Unity tools. Setup is not the MCP. The Creator Plugins catalogue is retiring from the apps; its page contains the retirement notice.

    An app says Not installed

    Choose its download/install action in Apps. Hub checks the release and verifies the download before asking you to approve installation. Unity Editor licensing and sign-in remain with Unity.

    My AI cannot see MCP tools

    Open Creator Works MCP and use its Connection guide when available, or check the existing client setup controls. Claude Code and Claude Desktop are separate clients; the Claude website is not Claude Desktop. Compatible MCP builds offer Desktop configuration on Windows and macOS, not Linux. Fully quit and reopen a changed client, then ask your AI to call get_bridge_status. Saved settings alone do not prove a live connection. The AI model and billing come from your chosen client/provider, not MCP.

    What happened to Creator Plugins?

    The in-app catalogue and new package imports have been retired. Existing imported assets, project files and import receipts are not removed. Already-installed Unity catalogue windows are not silently rewritten by Hub.

    AI token or usage costs are high

    Charges depend on your AI provider, client and model. Check provider billing and usage limits, reduce unnecessary context, disable fast/high-cost modes where available, and try a less expensive model for routine MCP tasks. MCP cannot set or cap your provider’s charges.

    Something failed

    Read the message shown in the app first. Retry discovery for app status, or refresh the relevant list. For project operations, close the project in Unity when asked and keep a separate backup. Include the app version and its local log when reporting a problem; remove private project paths or credentials first.
